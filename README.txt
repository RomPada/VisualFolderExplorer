VISUAL FOLDER EXPLORER v0.4.1
================================

Що нового у v0.4.1
------------------
- Програма запам’ятовує розмір вікна при закритті.
- Під час наступного запуску вікно відкривається з тією самою шириною і висотою.
- Якщо програма була закрита у розгорнутому стані, наступного разу вона також
  відкриється розгорнутою.
- Старий settings.json сумісний: після першого закриття нові параметри розміру
  будуть додані автоматично.

Усі можливості v0.4.0 збережені без змін.

Запуск
------
1. Розпакуйте всю папку VisualFolderExplorer_v0.4.1.
2. Двічі натисніть "Start Visual Folder Explorer.bat".
3. Під час першого запуску оберіть головну папку з матеріалами.
4. Надалі програма автоматично відкриватиме останню папку.

Робота із зображеннями
----------------------
- Клік по плитці зображення відкриває прев’ю праворуч.
- Клік по великому прев’ю збільшує його до 200%.
- У масштабі 200% затисніть ліву кнопку миші та перетягуйте зображення.
- Клік без руху по збільшеному зображенню повертає 100%.
- Правий клік по плитці: Вирізати / Копіювати / Перейменувати / Видалити.
- "До тексту" або Esc повертає праву панель до текстового файла.

Робота з текстовими файлами
----------------------------
- Підтримуються .txt та .md.
- Файли відображаються у лівому блоці разом із папками.
- Один клік по текстовому файлу відкриває його праворуч.
- Текст можна редагувати; "Зберегти" або Ctrl+S записує зміни.
- Стрілки ← → перемикають між текстовими файлами поточної папки.
- Правий клік по текстовому файлу: Відкрити / Вирізати / Копіювати /
  Перейменувати / Видалити.
- Правий клік по порожньому місцю у лівому блоці дозволяє вставити елементи з
  буфера або створити новий .txt/.md файл.

Вставлення
----------
- Скопіюйте або виріжте файл чи папку у Visual Folder Explorer або звичайному
  Провіднику Windows.
- У потрібній папці натисніть правою кнопкою по порожньому місцю блока "Папки".
- Якщо у буфері є файлові елементи, буде доступна команда "Вставити".
- Також працює Ctrl+V.
- Якщо елемент з такою назвою вже існує, програма не перезаписує його мовчки,
  а пропускає та показує попередження.

Видалення
---------
Команда "Видалити" не стирає файл безповоротно. Зображення та текстові файли
переміщуються до стандартного Кошика Windows, звідки їх можна відновити.

Збереження стану
----------------
Налаштування зберігаються локально у профілі Windows:
%LOCALAPPDATA%\VisualFolderExplorer\settings.json

Там зберігаються остання папка, історія навігації та розмір/стан вікна.

Підтримувані зображення
-----------------------
JPG, JPEG, PNG, BMP, GIF, TIFF. WEBP працює, якщо відповідний кодек доступний
WPF у Windows.

Вимоги
------
Windows 10/11, Windows PowerShell 5.1 та .NET Framework/WPF.

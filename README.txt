VISUAL FOLDER EXPLORER
======================

Що це
-----
Windows-додаток для перегляду папок, у яких зберігаються зображення та текстові файли.

Запуск
------
1. Розпакуйте всю папку VisualFolderExplorer у будь-яке місце на Windows.
2. Двічі натисніть "Start Visual Folder Explorer.bat".
3. Оберіть кореневу папку з вашими матеріалами.

Як працює
---------
- Ліворуч: підпапки поточної папки.
- По центру: усі підтримувані зображення плитками.
- Праворуч: вміст .txt-файлу.
- Якщо .txt-файлів кілька, перемикайте їх стрілками ← → внизу текстової панелі.
- Над стрілками/поруч показуються ім'я поточного текстового файла та номер, наприклад 2 / 4.
- Якщо є файл "Назва папки_текст.txt", він показується першим.
- Подвійний клік по папці відкриває її.
- Клік по плитці зображення відкриває велике прев'ю.
- F5 оновлює вміст поточної папки.
- Кнопки зверху: Назад, Вгору, До кореневої папки, Обрати іншу папку.

Підтримувані зображення
-----------------------
JPG, JPEG, PNG, BMP, GIF, TIFF. WEBP буде показаний, якщо Windows має відповідний кодек для WPF; інакше для нього може не бути прев'ю.

Важливо
-------
Програма нічого не переміщує, не видаляє і не змінює у ваших папках. Текст відкривається лише для читання.

Вимоги
------
Windows 10/11 з Windows PowerShell 5.1 та .NET Framework/WPF (стандартно присутні в типових інсталяціях Windows 10/11).

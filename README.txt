VISUAL FOLDER EXPLORER v0.3.1
================================

Що виправлено у v0.3.1
------------------------
- Виправлено помилку запуску PowerShell ParseException у рядках зі словом "превʼю".
- Причиною були типографічні апострофи, які Windows PowerShell 5.1 трактує як
  лапки всередині рядка. Тепер використовується безпечний символ апострофа.
- Функціональність v0.3.0 не змінена.

Що нового у v0.3.0
------------------
- У правому прев'ю зображення лівий клік перемикає масштаб 100% / 200%.
- Для плиток зображень додано меню правою кнопкою миші:
  Вирізати, Копіювати, Перейменувати, Видалити.
- У лівому блоці "Папки" тепер показуються не тільки підпапки, а й .txt/.md файли.
- Для .txt/.md файлів у лівому блоці доступне меню правою кнопкою:
  Відкрити, Вирізати, Копіювати, Перейменувати, Видалити.
- Подвійний клік по текстовому файлу відкриває його у правій панелі.
- Правий клік по порожньому місцю у блоці "Папки" відкриває меню створення:
  TXT-файл або Markdown-файл (.md).
- Видалення зображень і текстових файлів виконується через Кошик Windows,
  а не безповоротно.
- Вирізати/Копіювати використовують системний буфер обміну Windows, тому файл
  можна вставити у звичайному Провіднику Windows.
- Усі можливості v0.2.0 збережені: редагування .txt/.md, Ctrl+S, збереження,
  перемикання між текстовими файлами, прев'ю праворуч, пам'ять останньої папки
  та історія навігації.

Запуск
------
1. Розпакуйте всю папку VisualFolderExplorer_v0.3.1.
2. Двічі натисніть "Start Visual Folder Explorer.bat".
3. Під час першого запуску оберіть головну папку з матеріалами.
4. Надалі програма автоматично відкриватиме останню папку.

Робота із зображеннями
----------------------
- Клік по плитці зображення відкриває прев'ю праворуч.
- Клік по великому прев'ю збільшує його до 200%.
- Повторний клік повертає стандартний масштаб.
- Правий клік по плитці: Вирізати / Копіювати / Перейменувати / Видалити.
- "До тексту" або Esc повертає праву панель до текстового файла.

Робота з текстовими файлами
----------------------------
- Підтримуються .txt та .md.
- Файли відображаються у лівому блоці разом із папками.
- Подвійний клік відкриває вибраний текстовий файл праворуч.
- Текст можна редагувати; "Зберегти" або Ctrl+S записує зміни.
- Стрілки ← → перемикають між текстовими файлами поточної папки.
- Правий клік по текстовому файлу: Відкрити / Вирізати / Копіювати /
  Перейменувати / Видалити.
- Правий клік по порожньому місцю у лівому блоці дозволяє створити новий
  .txt або .md файл.

Видалення
---------
Команда "Видалити" не стирає файл безповоротно. Зображення та текстові файли
переміщуються до стандартного Кошика Windows, звідки їх можна відновити.

Збереження стану
----------------
Налаштування зберігаються локально у профілі Windows:
%LOCALAPPDATA%\VisualFolderExplorer\settings.json

Підтримувані зображення
-----------------------
JPG, JPEG, PNG, BMP, GIF, TIFF. WEBP працює, якщо відповідний кодек доступний
WPF у Windows.

Вимоги
------
Windows 10/11, Windows PowerShell 5.1 та .NET Framework/WPF.

VISUAL FOLDER EXPLORER v0.1.1
================================

Що нового у v0.1.1
------------------
- Кнопку "До тексту" перенесено в ліву частину заголовка правої панелі.
- Виправлено стан верхніх кнопок навігації після автоматичного відновлення останньої папки.
- Кнопка "Назад" відновлює збережену історію; якщо історії ще немає, при старті використовується батьківська папка поточної папки.
- Кнопка "Вгору" тепер працює відразу після запуску і дозволяє переходити до батьківської папки, як у Windows Explorer.
- Кнопка "Додому" активна після завантаження збереженого кореня та повертає до обраної головної папки.
- Історія навігації зберігається між запусками.
- Остання відкрита папка продовжує автоматично відновлюватися.

Запуск
------
1. Розпакуйте всю папку VisualFolderExplorer_v0.1.1.
2. Двічі натисніть "Start Visual Folder Explorer.bat".
3. Під час першого запуску оберіть головну папку з матеріалами.
4. Надалі програма автоматично відкриватиме останню папку.

Як працює
---------
- Ліворуч: підпапки поточної папки.
- По центру: зображення плитками.
- Праворуч за замовчуванням: текстовий файл.
- Якщо .txt-файлів декілька, стрілки ← → перемикають між ними.
- Клік по зображенню: прев'ю з'являється у правій панелі замість тексту.
- "До тексту" або Esc: повернення до тексту.
- Подвійний клік по папці відкриває її.
- F5 оновлює поточну папку.
- Верхні кнопки: Назад, Вгору, Додому, Обрати папку.

Збереження стану
----------------
Налаштування зберігаються локально у профілі Windows:
%LOCALAPPDATA%\VisualFolderExplorer\settings.json

Програма не змінює ваші картинки або текстові файли.

Підтримувані зображення
-----------------------
JPG, JPEG, PNG, BMP, GIF, TIFF. WEBP працює, якщо відповідний кодек доступний WPF у Windows.

Вимоги
------
Windows 10/11, Windows PowerShell 5.1 та .NET Framework/WPF.

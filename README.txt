VISUAL FOLDER EXPLORER v0.2.0
================================

Що нового у v0.2.0
------------------
- Додано редагування текстових файлів прямо у правій панелі.
- Підтримуються як .txt, так і .md файли.
- Додано кнопку "Зберегти".
- Ctrl+S зберігає поточний текстовий файл.
- Біля назви файла показується позначка "• незбережено", якщо текст змінено.
- При переході до іншого текстового файла, папки, оновленні F5 або закритті програми
  з'являється запит: зберегти зміни, відкинути їх чи скасувати дію.
- Програма намагається зберігати початкове кодування текстового файла
  (UTF-8/UTF-16/UTF-32; для старих файлів використовується системне кодування Windows).
- Усі можливості v0.1.1 збережені: прев'ю картинок праворуч, пам'ять останньої папки,
  історія навігації та перемикання між кількома текстовими файлами.

Запуск
------
1. Розпакуйте всю папку VisualFolderExplorer_v0.2.0.
2. Двічі натисніть "Start Visual Folder Explorer.bat".
3. Під час першого запуску оберіть головну папку з матеріалами.
4. Надалі програма автоматично відкриватиме останню папку.

Редагування тексту
------------------
- Відкрийте папку, у якій є .txt або .md файл.
- Праворуч можна одразу редагувати його вміст.
- Натисніть "Зберегти" або Ctrl+S.
- Якщо файлів декілька, стрілки ← → перемикають між ними.
- Перед перемиканням програма попередить про незбережені зміни.

Як працює
---------
- Ліворуч: підпапки поточної папки.
- По центру: зображення плитками.
- Праворуч за замовчуванням: редагований .txt/.md файл.
- Клік по зображенню: прев'ю з'являється у правій панелі замість тексту.
- "До тексту" або Esc: повернення до тексту.
- Подвійний клік по папці відкриває її.
- F5 оновлює поточну папку.
- Верхні кнопки: Назад, Вгору, Додому, Обрати папку.

Збереження стану
----------------
Налаштування зберігаються локально у профілі Windows:
%LOCALAPPDATA%\VisualFolderExplorer\settings.json

Підтримувані зображення
-----------------------
JPG, JPEG, PNG, BMP, GIF, TIFF. WEBP працює, якщо відповідний кодек доступний WPF у Windows.

Вимоги
------
Windows 10/11, Windows PowerShell 5.1 та .NET Framework/WPF.

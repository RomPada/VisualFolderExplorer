VISUAL FOLDER EXPLORER v0.5.0
================================

Що нового у v0.5.0
------------------
- Масштаб прев'ю зображення збільшено з 200% до 300%.
- У масштабі 300% зображення, як і раніше, можна перетягувати затиснутою
  лівою кнопкою миші.
- Плитка зображення, яке зараз відкрите у прев'ю, має помітне активне виділення.
- Після повернення з прев'ю до тексту остання вибрана картинка залишається
  виділеною м'якшим кольором.
- Markdown-файли (.md) за замовчуванням відкриваються у відформатованому
  вигляді, а не як звичайний текст із символами #, ** тощо.
- Для Markdown є кнопка "Редагувати". Вона відкриває вихідний Markdown для
  редагування; кнопка "Перегляд" повертає відформатований вигляд.
- Підтримано базове форматування Markdown: заголовки, жирний і курсивний текст,
  марковані та нумеровані списки, цитати, горизонтальні лінії, inline-code,
  блоки коду та візуальне оформлення посилань.

Усі можливості v0.4.1 збережені.

Запуск
------
1. Розпакуйте всю папку VisualFolderExplorer_v0.5.0.
2. Двічі натисніть "Start Visual Folder Explorer.bat".
3. Програма відкриє останню папку та відновить розмір/стан вікна.

Робота із зображеннями
----------------------
- Клік по плитці зображення відкриває прев'ю праворуч.
- Відкрита у прев'ю картинка виділена яскравіше у блоці "Зображення".
- Клік по великому прев'ю збільшує його до 300%.
- У масштабі 300% затисніть ліву кнопку миші та перетягуйте зображення.
- Клік без руху по збільшеному зображенню повертає 100%.
- "До тексту" або Esc повертає праву панель до текстового файла; остання
  вибрана картинка залишається виділеною м'якшим кольором.
- Правий клік по плитці: Вирізати / Копіювати / Перейменувати / Видалити.

Робота з TXT та Markdown
------------------------
- .txt відкривається у звичайному редакторі.
- .md відкривається у відформатованому Markdown-перегляді.
- Для .md натисніть "Редагувати", щоб побачити та змінювати вихідну розмітку.
- У режимі редагування кнопка змінюється на "Перегляд".
- "Зберегти" або Ctrl+S записує зміни у вихідний файл.
- Стрілки ← → перемикають між текстовими файлами поточної папки.
- Файли .txt та .md відображаються у лівому блоці "Папки" та відкриваються
  одним кліком.

Файлові операції
----------------
- Правий клік по зображенню: Вирізати / Копіювати / Перейменувати / Видалити.
- Правий клік по текстовому файлу: Відкрити / Вирізати / Копіювати /
  Перейменувати / Видалити.
- Правий клік по порожньому місцю у блоці "Папки": Вставити (коли у буфері
  є файл/папка), створити TXT або Markdown.
- Працює Ctrl+V для вставлення у поточну папку.
- Видалені з програми файли переміщуються до стандартного Кошика Windows.

Збереження стану
----------------
Налаштування зберігаються локально у профілі Windows:
%LOCALAPPDATA%\VisualFolderExplorer\settings.json

Там зберігаються остання папка, історія навігації та розмір/стан вікна.

Підтримувані зображення
-----------------------
JPG, JPEG, PNG, BMP, GIF, TIFF. WEBP працює, якщо відповідний кодек доступний
WPF у Windows.

Вимоги
------
Windows 10/11, Windows PowerShell 5.1 та .NET Framework/WPF.

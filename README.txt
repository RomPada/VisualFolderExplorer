VISUAL FOLDER EXPLORER v0.1.0
================================

Що нового у v0.1.0
------------------
- Виправлено помилку при натисканні на зображення (Show-ImagePreview is not recognized).
- Прев'ю зображення тепер відкривається прямо у правій панелі замість тексту.
- Кнопка "До тексту" повертає праву панель до текстового опису.
- Esc також повертає з прев'ю до тексту.
- Програма запам'ятовує останню відкриту папку.
- Після наступного запуску остання папка відкривається автоматично, без повторного вибору адреси.
- Якщо збережена папка була видалена або недоступна, програма запропонує вибрати папку заново.

Запуск
------
1. Розпакуйте всю папку VisualFolderExplorer_v0.1.0.
2. Двічі натисніть "Start Visual Folder Explorer.bat".
3. Під час першого запуску оберіть кореневу папку з матеріалами.
4. Надалі програма автоматично відкриватиме останню папку, в якій ви працювали.

Як працює
---------
- Ліворуч: підпапки поточної папки.
- По центру: зображення плитками.
- Праворуч за замовчуванням: текстовий файл.
- Якщо .txt-файлів декілька, стрілки ← → перемикають між ними.
- Клік по зображенню: його прев'ю з'являється у правій панелі замість тексту.
- "До тексту" або Esc: повернення до тексту.
- Подвійний клік по папці відкриває її.
- F5 оновлює поточну папку.
- Верхні кнопки: Назад, Вгору, До кореневої папки, Обрати іншу папку.

Збереження останньої папки
--------------------------
Налаштування зберігаються локально у профілі Windows:
%LOCALAPPDATA%\VisualFolderExplorer\settings.json

Програма не змінює ваші картинки або текстові файли.

Підтримувані зображення
-----------------------
JPG, JPEG, PNG, BMP, GIF, TIFF. WEBP працює, якщо відповідний кодек доступний WPF у Windows.

Вимоги
------
Windows 10/11, Windows PowerShell 5.1 та .NET Framework/WPF.

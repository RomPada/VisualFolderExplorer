VISUAL FOLDER EXPLORER v0.7.2
================================

Що нового у v0.7.2
------------------
- Виправлено XAML-помилку запуску, пов’язану зі стилем смуги прокрутки.
- Стилізований повзунок прокрутки збережено, але реалізовано суміснішим способом.
- Виправлено номер версії у BAT-вікні запуску.
- Лівий блок перейменовано з "Папки" на "Провідник".
- У блоці "Зображення" додано сортування:
  за назвою, датою зміни, датою створення або розміром.
- Для кожного способу сортування доступні звичайний (↑) і зворотний (↓) напрямки.
- Обраний спосіб сортування запам'ятовується між запусками програми.
- У "Провіднику" тепер можна створювати нові папки через правий клік по порожньому місцю.
- Правий клік по папці відкриває меню: Відкрити / Вирізати / Копіювати /
  Перейменувати / Видалити.
- Видалення папки переміщує всю папку до стандартного Кошика Windows, а не стирає її безповоротно.
- Папки можна копіювати або вирізати і вставляти через меню "Вставити" чи Ctrl+V.

Усі можливості v0.5.0 збережені.

Запуск
------
1. Розпакуйте всю папку VisualFolderExplorer_v0.7.2.
2. Двічі натисніть "Start Visual Folder Explorer.bat".
3. Програма відкриє останню папку та відновить розмір/стан вікна.

Сортування зображень
--------------------
У верхній частині блока "Зображення" є два списки:
- поле сортування: За назвою / За датою зміни / За датою створення / За розміром;
- напрямок: Звичайне ↑ / Зворотне ↓.

Для дат звичайний напрямок означає від старіших до новіших, зворотний — від
новіших до старіших. Для назви — від A/А до Z/Я і навпаки.

Провідник
---------
- Подвійний клік по папці відкриває її.
- Один клік по TXT або MD відкриває файл у правій панелі.
- Правий клік по папці: Відкрити / Вирізати / Копіювати / Перейменувати / Видалити.
- Правий клік по текстовому файлу: Відкрити / Вирізати / Копіювати /
  Перейменувати / Видалити.
- Правий клік по порожньому місцю: Вставити (якщо в буфері є файли або папки),
  Створити папку, Створити TXT-файл, Створити Markdown-файл.
- Ctrl+V вставляє скопійовані або вирізані файли/папки у поточне розміщення.
- Видалені файли та папки відправляються до Кошика Windows.

Робота із зображеннями
----------------------
- Клік по плитці відкриває прев'ю праворуч.
- Відкрита картинка виділена яскравіше; після повернення до тексту остання
  вибрана картинка залишається виділеною м'якше.
- Клік по прев'ю збільшує його до 300%.
- У масштабі 300% затисніть ліву кнопку миші та перетягуйте зображення.
- Клік без руху по збільшеному зображенню повертає 100%.
- Правий клік по плитці: Вирізати / Копіювати / Перейменувати / Видалити.

TXT та Markdown
----------------
- .txt відкривається у звичайному редакторі.
- .md за замовчуванням відкривається у відформатованому Markdown-перегляді.
- Кнопка "Редагувати" показує вихідну Markdown-розмітку; "Перегляд" повертає
  відформатований режим.
- "Зберегти" або Ctrl+S записує зміни у файл.
- Стрілки ← → перемикають між текстовими файлами поточної папки.

Збереження стану
----------------
Налаштування зберігаються у:
%LOCALAPPDATA%\VisualFolderExplorer\settings.json

Зберігаються остання папка, історія навігації, розмір/стан вікна та сортування
зображень.

Підтримувані зображення
-----------------------
JPG, JPEG, PNG, BMP, GIF, TIFF. WEBP працює, якщо відповідний кодек доступний
WPF у Windows.

Вимоги
------
Windows 10/11, Windows PowerShell 5.1 та .NET Framework/WPF.

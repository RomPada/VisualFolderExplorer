# Visual Folder Explorer v0.11.0

Visual Folder Explorer — легкий Windows-додаток для роботи з папками, у яких одночасно зберігається велика кількість зображень та TXT/Markdown-описи. Основна ідея: бачити плитки зображень і пов'язаний текст в одному вікні.

> Основний README англійською: `README.md`.
> Історія версій: `PATCHLIST.md`.

## Вимоги

- Windows 10 або Windows 11
- Windows PowerShell 5.1
- .NET Framework / WPF, що входять до Windows
- Python, Node.js та сторонні runtime не потрібні

## Запуск

1. Повністю розпакуйте папку `VisualFolderExplorer_v0.11.0`.
2. Двічі натисніть `Start Visual Folder Explorer.bat`.
3. Під час першого запуску оберіть кореневу папку з матеріалами.
4. Надалі програма відкриватиме останню папку та відновлюватиме збережений стан вікна.

## Основні блоки

- **Провідник** — папки та TXT/MD-файли поточного розміщення.
- **Зображення** — плитки зображень, сортування та файлові операції.
- **Текст / Прев'ю** — вміст TXT/Markdown або прев'ю вибраної картинки.

## Провідник

- Подвійний клік по папці відкриває її.
- Один клік по `.txt` або `.md` відкриває файл праворуч.
- Правий клік по папці або текстовому файлу відкриває файлові операції.
- Правий клік по порожньому місцю дозволяє вставити файли, створити папку, TXT або Markdown-файл.
- Вирізання, копіювання та вставлення працюють через буфер Windows.
- Якщо під час вставлення виникає конфлікт назв, новий файл або папка автоматично отримує суфікс `_1`, `_2` тощо.
- Видалені файли та папки відправляються до Кошика Windows.

## Зображення

Підтримуються JPG, JPEG, PNG, BMP, GIF, TIFF/TIF та WEBP, якщо відповідний WPF-кодек доступний у Windows.

- Зображення відображаються плитками.
- Сортування: за назвою, датою зміни, датою створення або розміром.
- Доступний звичайний і зворотний порядок.
- Обраний тип сортування запам'ятовується між запусками.
- Клік по картинці відкриває її у правому прев'ю.
- Картинка, що зараз у прев'ю, виділяється яскравіше.
- Після повернення до тексту остання вибрана картинка залишається виділена м'якше.
- Маркер на скролбарі блока «Зображення» показує приблизний рівень, де знаходиться вибрана картинка у великій папці.
- Правий клік по картинці: вирізати, копіювати, перейменувати, видалити.
- Правий клік по порожньому місцю блока «Зображення» дозволяє вставити вміст буфера у поточну папку.

### Зум прев'ю

- Клік по прев'ю збільшує його до **300%**.
- У збільшеному режимі затисніть ліву кнопку миші та рухайте картинку.
- Клік без перетягування повертає масштаб 100%.

## TXT та Markdown

- TXT відкривається у текстовому редакторі.
- Markdown за замовчуванням відкривається у відформатованому режимі.
- Кнопка **Редагувати** показує Markdown-розмітку, а **Перегляд** повертає відформатований вигляд.
- Збереження: кнопка **Зберегти** або `Ctrl+S`.
- Стрілки ліворуч/праворуч під текстом перемикають текстові файли поточної папки.
- При перемиканні стрілками відповідний файл також виділяється у «Провіднику».


## Перенесення зображень

Між кнопкою **«Обрати папку»** та перемикачем UA/EN додано кнопку **«Перенести»**. Вона відкриває стилізовану випадаючу панель:

- поле **«Звідки»** автоматично містить поточну відкриту папку програми;
- поле **«Куди»** відновлює останню папку, куди успішно переносили зображення; до першого перенесення воно порожнє;
- для обох шляхів є кнопки вибору папки;
- переносяться підтримувані зображення лише з самої папки, без обходу підпапок;
- початкові назви файлів зберігаються; якщо у папці призначення вже є файл з такою назвою, додається суфікс `_1`, `_2` тощо;
- остання успішна папка призначення зберігається у `settings.json`.

## Спільні стилі інтерфейсу

Усі повторно використовувані стилі винесені у `Styles.xaml`. Нові кнопки, контекстні меню, ComboBox, поля вводу, діалоги, popup-панелі та скролбари мають використовувати ці стилі, щоб нові функції автоматично виглядали в одному стилі з програмою.

## Мови інтерфейсу

У правому верхньому куті є перемикач **UA / EN**. Він перемикає інтерфейс між українською та англійською мовами. Обрана мова запам'ятовується між запусками. Разом із нею змінюються основні написи, сортування, контекстні меню, вікна файлових операцій і попередження про незбережені зміни.

## Продуктивність

Гілка 0.9.x оптимізована для папок із сотнями та навіть 1000+ зображень:

- прев'ю підвантажуються поступово, щоб вікно не зависало;
- зменшений технічний розмір thumbnail для меншого навантаження на RAM і CPU;
- контекстні меню картинок створюються лише за потреби;
- прибраний повторний повний перерахунок виділення плиток під час завантаження;
- вміст папки читається один раз і використовується всіма блоками;
- великі колекції обробляються невеликими порціями.

## Збереження налаштувань

Стан програми зберігається у:

```text
%LOCALAPPDATA%\VisualFolderExplorer\settings.json
```

Запам'ятовуються остання папка, історія навігації, розмір/стан вікна, налаштування сортування, вибрана мова інтерфейсу та остання папка призначення для перенесення зображень.

## Файли проєкту

- `VisualFolderExplorer.ps1` — код програми
- `Styles.xaml` — спільні стилі кнопок, меню, полів, popup-панелей, діалогів і скролбарів
- `Start Visual Folder Explorer.bat` — запуск програми
- `README.md` — основний README англійською
- `README_UA.md` — README українською
- `PATCHLIST.md` — двомовна історія версій

## Версії

Використовується схема Semantic Versioning:

- PATCH — виправлення та невеликі зміни без порушення сумісності, наприклад `v0.10.0 → v0.10.1`;
- MINOR — нові сумісні функції, наприклад `v0.10.1 → v0.11.0`;
- MAJOR — великі або несумісні релізи, наприклад `v0.x.x → v1.0.0`.
